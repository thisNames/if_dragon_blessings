# If Dragon Blessings（龙之祝福）

一个 Minecraft Forge 1.20.1 模组，为玩家提供三种「龙的祝福」攻击方式。

攻击方式与物品无关：持有对应祝福效果（buff）后，攻击命中目标即可触发对应的龙之攻击特效。

## 功能

### 火龙（Fire Dragon）

- **祝福效果**：`fire_attack`（火龙的祝福）
- **攻击特效**：点燃目标 5 秒 + 烈焰标记 5 秒 + 击退

### 冰龙（Ice Dragon）

- **祝福效果**：`ice_attack`（冰龙的恩惠）
- **攻击特效**：冰封 + 缓慢 III + 挖掘疲劳 III（10 秒）+ 冰块装饰渲染 + 消失时碎冰音效与粒子

### 电龙（Lightning Dragon）

- **祝福效果**：`lightning_attack`（电龙的庇护）
- **攻击特效**：闪电链（多目标伤害传导）+ 感电定身 3 秒

## 效果分类

| 类型 | 效果 | 说明 |
|---|---|---|
| 攻击 buff（正面） | `fire_attack` / `ice_attack` / `lightning_attack` | 施加给攻击者，攻击时触发对应攻击方式 |
| 状态效果（负面） | `frozen`（冰封）/ `blaze`（烈焰）/ `shocked`（感电） | 施加给被击中的目标，**等级跟随对应正面 buff 的等级** |

## 等级与倍率

三种祝福 buff 均支持等级（`/effect give ... <时长> <等级>` 的最后一个参数，0 表示 I 级）。
等级超过配置上限时按上限计算（默认上限 3 级，可在配置中调整）。

**倍率公式**（三种龙共用，实现见 `api/AttackMultipliers.java`）：

```
倍率 = 1.0 + min(等级, 最大有效等级) × 0.25
```

**各等级倍率与实际效果**（默认配置 `maxLevel = 3`）：

| 等级 | 倍率 | 火龙：点燃/烈焰标记 | 火龙：击退强度 | 冰龙：效果持续 | 电龙：中心伤害 | 电龙：链式基础伤害 |
|---|---|---|---|---|---|---|
| 0（I 级） | ×1.00 | 5 秒 | 1.00 | 10 秒 | 5.0 | 4.0 |
| 1（II 级） | ×1.25 | 6.25 秒 | 1.25 | 12.5 秒 | 6.25 | 5.0 |
| 2（III 级） | ×1.50 | 7.5 秒 | 1.50 | 15 秒 | 7.5 | 6.0 |
| 3（IV 级，默认满级） | ×1.75 | 8.75 秒 | 1.75 | 17.5 秒 | 8.75 | 7.0 |

> 提高配置上限后各等级继续按 ×0.25/级 递增（例如 10 级 = ×3.50）；
> 未到上限前，所有数值 = 基数 × 倍率。

**各龙随等级成长的内容**：

| 龙 | 随倍率增强 | 随等级线性成长（封顶配置上限） | 不随等级变化 |
|---|---|---|---|
| 火龙 | 点燃时长（5 秒基数）、烈焰标记时长（100 tick 基数）、击退强度（1.0 基数） | — | — |
| 冰龙 | 冰封 / 缓慢 III / 挖掘疲劳 III 的持续时长（200 tick 基数） | — | 缓慢与挖掘疲劳的等级（固定 III） |
| 电龙 | 中心目标伤害（5.0 基数）、链式基础伤害（4.0 基数） | 链搜索半径（8 格起步 + 每级 2 格，上限 14 格）、链目标数（6 起步 + 每级 1，上限 9） | 链式伤害递减比例、感电定身时长（固定 3 秒） |

**电龙链式成长公式**（独立于倍率算法，等级 0 即为起始值，每级增量固定：半径 +2 格、目标 +1）：

```
实际搜索半径 = min(起始半径 + 等级 × 2, searchRange 上限)
实际目标数量 = min(起始数量 + 等级 × 1, maxTargets 上限)
```

**相关配置**（`config/if_dragon_blessings-common.toml`）：

| 配置项 | 说明 | 默认 | 范围 |
|---|---|---|---|
| `dragonAttacks.fireAttackMaxLevel` | 火龙之力最大有效等级 | 3 | 1~10 |
| `dragonAttacks.iceAttackMaxLevel` | 冰龙之力最大有效等级 | 3 | 1~10 |
| `chainLightning.lightningAttackMaxLevel` | 电龙之力最大有效等级 | 3 | 1~10 |

等级示例：

```
/effect give @s if_dragon_blessings:fire_attack 60 2
```

（60 秒、III 级火龙的祝福，按 ×1.50 倍率计算攻击特效）

## 环境要求

- Minecraft `1.20.1`
- Forge `47.4.10+`
- **零第三方依赖**（仅依赖 Forge 与原版）

## 构建

```bash
./gradlew build
```

构建产物位于 `build/libs/` 目录。

## 使用

通过命令给自己附加祝福效果（创造模式下），然后攻击目标即可：

```
/effect give @s if_dragon_blessings:fire_attack 60 0
/effect give @s if_dragon_blessings:ice_attack 60 0
/effect give @s if_dragon_blessings:lightning_attack 60 0
```

三种祝福可同时持有，攻击时会同时触发对应特效，互不冲突。
