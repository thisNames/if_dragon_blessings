# If Dragon Blessings（龙之祝福）

一个 Minecraft Forge 1.20.1 模组，为玩家提供三种「龙的祝福」攻击方式。

攻击方式与物品无关：持有对应祝福效果（buff）后，攻击命中目标即可触发对应的龙之攻击特效。

## 三种祝福

### 火龙（Fire Dragon）

- 祝福效果：`fire_attack`
- 攻击效果：点燃目标（5 秒 × 倍率）+ 烈焰标记 + 击退
- 目标带有冰封时不会点燃（冰克火）

### 冰龙（Ice Dragon）

- 祝福效果：`ice_attack`
- 攻击效果：冰封标记 + 缓慢 III + 挖掘疲劳 III（10 秒 × 倍率）+ 灭火 + 碎冰

### 电龙（Lightning Dragon）

- 祝福效果：`lightning_attack`
- 攻击效果：闪电链（中心 + 周围多个目标，AOE）+ 感电定身 3 秒
- 伤害模式：默认「魔法电」；可配置为「原版雷击电」
## 元素反应

三种基础状态（`frozen` 冰封 / `blaze` 烈焰 / `shocked` 感电，固定 3 秒）两两组合会触发**元素反应**，造成额外魔法伤害。

### 反应组合

| 组合 | 反应 |
|---|---|
| 冰 + 火 | 融化 |
| 冰 + 电 | 超导 |
| 火 + 电 | 超载 |

触发规则：**攻击者施加一种元素时，检查目标身上已有的另外两种元素**。因此目标同时带多个元素标记时，一次攻击可同时触发多个反应。

| 攻击方式 | 施加标记 | 触发的反应 |
|---|---|---|
| 火龙 | `blaze` | `frozen` → 融化、`shocked` → 超载 |
| 冰龙 | `frozen` | `blaze` → 融化、`shocked` → 超导 |
| 电龙 | `shocked` | `frozen` → 超导、`blaze` → 超载 |

### 伤害计算

单个反应伤害 = 基础伤害 `10.0` ×（施加元素等级 × 已有元素等级 × 0.1），等级按 1 起算（I 级 = 1）。

| 等级组合 | 倍率 | 单个反应伤害 | 心数 |
|---|---|---|---|
| 1×1 | 10% | 1.0 | 半颗心 |
| 1×2 / 2×1 | 20% | 2.0 | 1 颗心 |
| 2×2 | 40% | 4.0 | 2 颗心 |
| 2×3 / 3×2 | 60% | 6.0 | 3 颗心 |
| 3×3（默认满级） | 90% | 9.0 | 4.5 颗心 |

- **伤害合并**：同一次攻击触发的多个反应伤害会累加成一次结算（电龙还会与电击伤害合并），避免原版无敌帧吞掉叠加伤害。
- **伤害归属**：反应伤害使用 `indirectMagic(attacker)` 魔法伤害源，击杀统计、经验、掉落物归攻击者。
- **反应标记**：触发后目标短暂挂上纯标记效果（`melt` / `superconduct` / `overload`），仅作视觉提示，不参与下一次反应连锁。

## 等级与倍率

三种祝福均支持等级（`/effect` 的等级参数，0 表示 I 级），等级超过配置上限按上限计算（默认上限 3 级）。

**倍率公式**（三种龙共用）：

```
倍率 = 1.0 + min(等级, 最大有效等级) × 0.25
```

### 各等级效果（默认上限 3 级）

| 等级 | 倍率 | 火龙点燃 | 火龙击退 | 冰龙效果时长 | 电龙中心伤害 | 电龙链式基础伤害 |
|---|---|---|---|---|---|---|
| 0（I） | ×1.00 | 5 秒 | 1.0 | 10 秒 | 5.0 | 4.0 |
| 1（II） | ×1.25 | 6.25 秒 | 1.25 | 12.5 秒 | 6.25 | 5.0 |
| 2（III） | ×1.50 | 7.5 秒 | 1.50 | 15 秒 | 7.5 | 6.0 |
| 3（IV，默认满级） | ×1.75 | 8.75 秒 | 1.75 | 17.5 秒 | 8.75 | 7.0 |

### 电龙闪电链成长（独立于倍率算法）

```
搜索半径 = min(8 + 等级 × 2, 14)
目标数量 = min(6 + 等级 × 1, 9)
```

链式伤害逐级递减（每级 −12.5%，最低保留 10%）。

## 配置

配置文件：`config/if_dragon_blessings-common.toml`

| 配置项 | 说明 | 默认 |
|---|---|---|
| `elementalReactions.enabled` | 元素反应总开关 | `true` |
| `dragonAttacks.fireAttackMaxLevel` | 火龙之力最大有效等级 | `3` |
| `dragonAttacks.iceAttackMaxLevel` | 冰龙之力最大有效等级 | `3` |
| `chainLightning.lightningAttackMaxLevel` | 电龙之力最大有效等级 | `3` |
| `chainLightning.useVanillaLightning` | 电龙伤害模式（`false`=魔法电 / `true`=原版雷击电） | `false` |
| `chainLightning.centerDamage` | 闪电链中心目标伤害 | `5.0` |
| `chainLightning.chainDamageBase` | 闪电链链式基础伤害 | `4.0` |

## 使用

通过命令附加祝福效果（创造模式下），然后攻击目标即可：

```
/effect give @s if_dragon_blessings:fire_attack 60 0
/effect give @s if_dragon_blessings:ice_attack 60 0
/effect give @s if_dragon_blessings:lightning_attack 60 0
```

三种祝福可同时持有，攻击时会同时触发对应特效，互不冲突。

## 环境要求

- Minecraft `1.20.1`
- Forge `47.4.10+`
- 零第三方依赖（仅依赖 Forge 与原版）

## 构建

```bash
./gradlew build
```

构建产物位于 `build/libs/` 目录。
